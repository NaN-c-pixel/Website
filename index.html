ESP32-S3 · Pocket computing

A tiny board.
A big idea.

HùngOS is an experimental pocket-computer interface built around the ESP32-S3. It brings useful tools, playful apps, and a browser-based control panel to a small device.

🗒️ Everyday tools

Small games and educational experiments designed for the pocket-computer idea.

Run it on your own board

The project is designed for an ESP32-S3 running MicroPython.

01 · PrepareSet up MicroPython and connect your ESP32-S3 to your computer.
02 · CopyFollow the setup instructions in the source repository to copy the project files and configure Wi-Fi.
03 · ConnectJoin the same local Wi-Fi network and open the device address shown by the board.

Built as an experiment

HùngOS is a personal hardware and software project. Features may change as the project develops.
