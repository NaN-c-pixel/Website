# HùngOS Website

A lightweight, responsive landing page for the HùngOS ESP32-S3 pocket-computer project.

## Files

- `index.html` — the complete static website (HTML and CSS; no build step required).

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Open the repository's **Settings**.
2. Open **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site; the Pages screen will show its public URL.

## Safety note

The landing page is separate from the ESP32 device interface. Do not publish Wi-Fi passwords, API keys, private network addresses, or other secrets. Keep the board's control interface on your trusted local network.

## Project source

The firmware and device project are maintained separately at https://github.com/NaN-c-pixel/Phone.
